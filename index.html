概念ネットワーク：理性と悟性

図の用語をクリックすると、意味・訳語・思想史上の関係が表示されます。

ドイツ語 / ドイツ観念論

Vernunft（理性）

従来の訳： 理性

訳語の検討案： 統合理性（試案）

意味： 個別の認識を超え、認識の全体的な関係や原理を考える能力。

関連概念： Verstand、Begriff、Urteil

思想史上の位置： カントとヘーゲルでは、悟性との関係が異なる。

※ 図の線は概念間の関連を示す模式図です。 すべてが同じ種類の関係や直接的な派生関係を意味するわけではありません。

async function loadDictionary() { const info = document.getElementById("info"); try { const response = await fetch("./dictionary.json"); if (!response.ok) { throw new Error("dictionary.jsonを読み込めませんでした"); } const dictionary = await response.json(); const data = {}; dictionary.terms.forEach(term => { data[term.id] = term; }); function selectNode(id) { const item = data[id]; if (!item) { if (id === "kant") { info.innerHTML = `
哲学史

Kant / Hegel

カントとヘーゲルでは、理性と悟性の関係が異なる。

カントは両者を区別し、ヘーゲルは悟性の固定的な区別を理性が捉え直す過程を重視する。

`; } return; } document.querySelectorAll(".node").forEach(node => { node.classList.toggle("selected", node.dataset.id === id); }); const translations = item.translation.join("、"); const proposals = item.proposals.length ? item.proposals.join("、") + "（" + item.proposalStatus + "）" : item.proposalStatus; const related = item.related .map(id => data[id]?.term || id) .join("、"); info.innerHTML = `
${item.language} / ${item.field}

${item.term}

従来の訳：${translations}

訳語の検討案：${proposals}

意味：${item.meaning}

思想家：${item.thinkers.join("、")}

関連概念：${related}

`; } document.querySelectorAll(".node").forEach(node => { node.addEventListener("click", () => selectNode(node.dataset.id) ); node.addEventListener("keydown", event => { if (event.key === "Enter" || event.key === " ") { event.preventDefault(); selectNode(node.dataset.id); } }); }); const edgePairs = { rv: ["vernunft", "verstand"], rb: ["vernunft", "begriff"], vu: ["verstand", "urteil"], bu: ["begriff", "urteil"], us: ["urteil", "schluss"] }; document.querySelectorAll(".relation-edge").forEach(edge => { function showRelation() { const pair = edgePairs[edge.dataset.relation]; const relation = pair && dictionary.relations.find(r => (r.from === pair[0] && r.to === pair[1]) || (r.from === pair[1] && r.to === pair[0]) ); if (relation) { info.innerHTML = `
${relation.type}

${data[relation.from]?.term || relation.from} と ${data[relation.to]?.term || relation.to}

関係の説明：${relation.description}

`; } else { info.innerHTML = `
思想史上の位置づけ

判断と思想史的展開

カントとヘーゲルでは、判断の論理学・認識論上の位置づけが異なる。

`; } document.querySelectorAll(".node").forEach(node => { node.classList.remove("selected"); }); } edge.addEventListener("click", showRelation); edge.addEventListener("keydown", event => { if (event.key === "Enter" || event.key === " ") { event.preventDefault(); showRelation(); } }); }); selectNode("vernunft"); } catch (error) { info.innerHTML = `

データ読み込みエラー

${error.message}

dictionary.jsonのファイル名と保存場所を確認してください。

`; } } loadDictionary();
